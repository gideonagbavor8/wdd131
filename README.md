# WDD131 – Dynamic Web Fundamentals Projects

This repository contains coursework and projects completed for the **BYU–Idaho WDD131: Dynamic Web Fundamentals** course.  
It showcases two major projects: **About Me** and the **Student Access Hub**.

---

## 📂 Projects

### 👤 About Me
A personal introduction site built with HTML and CSS.  
It highlights background, interests, and goals while demonstrating responsive design and semantic structure.

**Features**
- Clean, simple layout
- Personal biography and contact information
- Responsive styling for different screen sizes

👉 [Live Demo](https://about-me-wdd131.onrender.com/index.html)

---

### 🎓 Student Access Hub
A static site designed to provide students with easy access to resources and membership options.  
Built with HTML and CSS, focusing on usability and form validation.

**Features**
- Home page introducing the hub
- Join page with membership form
- Professional, accessible design
- Deployed via Render

👉 [Live Demo](https://professional-educators-hub-wdd231.onrender.com/join.html)

---

## 🛠️ Technologies Used
- **HTML5** – structure and content
- **CSS3** – styling and layout
- **Render** – deployment
- **VS Code** – development environment
